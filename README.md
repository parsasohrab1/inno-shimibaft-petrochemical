# inno-shimi-baft-60ta — SPRO1

اسکلت (scaffold) محصول **SPRO1** (سامانه هوشمند بهینه‌سازی فرآیند، تولید و
انرژی) برای **شرکت پتروشیمی شیمی بافت**، بر اساس سند نیازمندی‌های نرم‌افزار
(SRS) رسمی این محصول — پیاده‌سازی کامل در [docs/SRS.md](docs/SRS.md).

> **این یک اسکلت است، نه محصول کامل.** ساختار دایرکتوری، یک برنامه FastAPI
> قابل اجرا، یک پوسته React+Vite، و چهار ماژول با منطق جای‌نگه‌دار (heuristic)
> آماده شده‌اند؛ **هیچ مدل یادگیری ماشین واقعی آموزش ندیده و هیچ اتصال واقعی
> به DCS/Historian/LIMS برقرار نشده است.** جزئیات دقیق هر بخش در
> [docs/SRS.md بخش ۳.۱](docs/SRS.md) با ستون «وضعیت در این اسکلت» مشخص شده.

## ۱. منشأ این سند و یک تصحیح مسیر

کار روی این مخزن با یک نامه پیشنهاد عمومی محصول (ref. 14050616001،
[docs/vendor-proposal-reference.md](docs/vendor-proposal-reference.md))
آغاز شد. در میانه کار، نسخه رسمی و جزئیات‌دار SRS (با عنوان **SPRO1**،
استاندارد IEEE 830 / ISO/IEC/IEEE 29148، معیارهای پذیرش کمّی، فهرست تگ‌های
واقعی و تابع تولید داده سنتتیک) مستقیماً روی ریپازیتوری گیت‌هاب این محصول
منتشر شد (کامیت `f6d8b6d`). این سند به صورت مستقل دریافت و بررسی شد و اکنون
مرجع اصلی `docs/SRS.md` است؛ نامه اولیه صرفاً برای ردیابی تاریخی نگه داشته
شده.

## ۲. پروفایل شرکت پتروشیمی شیمی بافت (پژوهش وب مستقل)

منابع زیر از جست‌وجوی وب عمومی به‌دست آمده‌اند، **نه از کارفرما**؛ تاریخ هر
منبع ذکر شده چون برخی اعداد با سند SRS رسمی (بخش ۲.۱) تفاوت دارند.

- **محل و تأسیس:** واحد شیمی بافت در ماهشهر، استان خوزستان (منطقه ویژه
  اقتصادی پتروشیمی) قرار دارد؛ طبق یک پروفایل صنعتی ژاپنی (حدود سال ۲۰۱۵)
  این شرکت در سال ۱۹۹۹ میلادی تأسیس شده و واحد MTBE آن حدود سال ۲۰۰۲
  راه‌اندازی شده است.
  ([منبع: پروفایل صنعت پتروشیمی ایران، knak.jp](https://knak.jp/iran/iran-petchem-1.htm))
- **ظرفیت‌ها (منبع ۲۰۱۵، قدیمی):** MTBE حدود ۹۰ هزار تن/سال؛ رافینیت ۲
  حدود ۱۰۱ هزار تن/سال. **این عدد رافینیت ۲ با سند SRS رسمی این پروژه
  (۵۰,۰۰۰ تن/سال، بخش ۲.۱ SRS) مغایر است** — عدد SRS به‌عنوان مرجع فعلی
  کار در نظر گرفته شده چون از خود کارفرما/مجری صادر شده، اما این مغایرت
  صراحتاً گزارش می‌شود.
- **شرکت تابعه:** «شیمی‌تکس آریا» (Shimitex Aria) تولیدکننده MEK
  (متیل اتیل کتون) است و به ادعای خود شرکت (گزارش ۲۰۱۹)، تنها تولیدکننده
  MEK در خاورمیانه بوده است.
  ([منبع: Eghtesad Online (انگلیسی)، ۱۴ اوت ۲۰۱۹](https://www.eghtesadonline.com/en/news/748179/3-iranian-petrochem-companies-report-growth-rates))
- **عملکرد (۲۰۱۹، قدیمی):** رشد تولید ٪۷+ در سه‌ماهه اول ۲۰۱۹؛ صادرات حدود
  ۱۰ هزار تن به ارزش ۶ میلیون دلار در همان بازه.
  ([همان منبع](https://www.eghtesadonline.com/en/news/748179/3-iranian-petrochem-companies-report-growth-rates))
- **مالکیت:** گزارش‌های خبری بورسی (نبض بورس) شیمی‌بافت را زیرمجموعه
  **تاپیکو** (شرکت سرمایه‌گذاری نفت، گاز و پتروشیمی تأمین) معرفی می‌کنند و
  آن را در فهرست عرضه‌های اولیه احتمالی تاپیکو در بورس تهران ذکر می‌کنند
  (تاریخ دقیق این گزارش‌ها نامشخص بود).
  ([منبع: nabzebourse.com](https://nabzebourse.com/fa/news/135944/) ،
   [منبع دوم](https://nabzebourse.com/fa/news/109886/))
  **ارتباط مستقیم «شیمی بافت ← هلدینگ شستا» که در بریف این پروژه ذکر شده
  بود، در جست‌وجوی وب مستقل تأیید نشد** — شستا و تاپیکو در برخی گزارش‌ها
  به‌عنوان طرف‌های مرتبط نام برده شده‌اند، اما ارتباط مالکیتی مستقیمِ
  شیمی‌بافت با شستا پیدا نشد. مدیرعامل (مهندس احسان الداغی) و نماد بورسی
  مستقل نیز در جست‌وجوی وب مستقل تأیید نشدند؛ این دو مورد صرفاً طبق بریف
  کارفرما در این سند ذکر می‌شوند.
- **زنجیره فرآیندی عمومی (الگوی صنعتی، نه فلودیاگرام تأییدشده این واحد):**
  خوراک رافینیت ۱ (جریان مخلوط C4 حاوی ایزوبوتیلن) + متانول → راکتور
  اترایی کاتالیستی (رزین تبادل یونی اسیدی) → MTBE + رافینیت ۲ (باقیمانده
  فاقد ایزوبوتیلن). در واحد MEK، بوتن‌های رافینیت معمولاً از طریق
  هیدراتاسیون به سک-بوتانول و سپس دهیدروژناسیون کاتالیستی به MEK تبدیل
  می‌شوند — این یک الگوی عمومی شیمی صنعتی MTBE/MEK است، نه چیزی که برای
  پیکربندی واقعی واحدهای شیمی بافت تأیید شده باشد.
- **شدت مصرف انرژی واقعی (SEC بر حسب GJ/t):** هیچ رقم عمومی قابل اتکایی
  برای این واحد یافت نشد؛ باید از EI-401 واقعی (Historian) استخراج شود.

## ۳. چهار ماژول SPRO1

| M1 | هوش فرآیند و بهینه‌سازی شرایط عملیاتی | `backend/app/services/process_intelligence.py` |

## ۴. اجرای سریع (توسعه محلی)

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt    # ویندوز
# source .venv/bin/activate && pip install -r requirements.txt   # لینوکس/مک

uvicorn app.main:app --app-dir backend --port 8000
```

مرورگر: <http://127.0.0.1:8000/docs> (Swagger). در اولین اجرا با پایگاه‌داده
خالی، داده نمونه برچسب‌دار (`is_sample=1`) به‌صورت خودکار در پس‌زمینه ساخته
می‌شود (`AUTO_SEED=1` پیش‌فرض)؛ `/health` وضعیت seeding/ready را نشان می‌دهد.

**کاربران نمونه** (رمز پیش‌فرض `Demo@12345`، با متغیر محیطی `DEMO_PASSWORD`
قابل تغییر؛ فقط برای توسعه/دمو — پیش از هر استقرار واقعی تغییر دهید):
`admin` (مدیر سیستم) · `process` (مهندس فرآیند) · `energy` (مهندس انرژی و
خوراک) · `quality` (مهندس کیفیت).

### فرانت‌اند
```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```
مرورگر: <http://127.0.0.1:5173> — به بک‌اند روی پورت ۸۰۰۰ متصل می‌شود
(`VITE_API_BASE` در صورت نیاز).

### تست
```bash
python -m pytest     # از ریشه مخزن
```

## ۶. محدودیت‌های صریح (بخوانید پیش از هر تصمیم عملیاتی)

- هیچ اتصال واقعی به DCS، Historian یا LIMS پیاده نشده — `services/dcs_ingest.py`
  عمداً `NotImplementedError` می‌دهد تا با داده جعلیِ «زنده» اشتباه گرفته نشود.
  **تمام API صرفاً روی داده نمونه برچسب‌دار کار می‌کند.**
  - هیچ مدل یادگیری ماشین آموزش داده نشده؛ منطق هر ماژول صرفاً یک جای‌نگه‌دار
  ساده (میانگین، آستانه ثابت، درون‌یابی خطی) است — نه رگرسیون، نه
  طبقه‌بند، نه بهینه‌ساز محدودیت‌محور. جزئیات در docstring هر فایل سرویس.
- فهرست تگ‌های واحد MEK (`TI-501`, `TI-502`) ساخته این اسکلت است، نه بخشی
  از سند SRS رسمی (که فقط برای واحد MTBE فهرست تگ داده).
- پروفایل شرکت در بخش ۲ از منابع وب عمومی و قدیمی (۲۰۱۵ و ۲۰۱۹) است؛
  ارقام ظرفیت، مالکیت، مدیرعامل و نماد بورسی باید با منابع رسمی/کدال
  شرکت تطبیق داده شوند.
- امنیت فعلی (JWT + bcrypt + RBAC ساده) یک الگوی دمو است، نه پیاده‌سازی
  NFR-03 (TLS 1.3 باید توسط یک reverse proxy واقعی در استقرار تأمین شود).

`https://github.com/parsasohrab1/inno-shimibaft-petrochemical.git` تنظیم
شده، **بدون push**. آن ریموت از قبل دو کامیت دارد (یک README اولیه، سپس

واگذار شده و در این اجرا انجام نشده است.
